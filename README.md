Проект "Домашнее задание по основам верстки"
Описание:
Данный проект является образцом для создания HTML-документов со структурной страницей и подключенными к ним Bootstrap-стилями.

Применение:
1. Клонируйте репозитории:
    https://github.com/basinanatali-star/Django.git
2. Установите в зависимости:
    pip install -r requirements.txt
Использование:
Это учебный проект, поэтому можно использовать его как образец

Модули проекта:
Модуль page_catalog.html содержит прототип веб-страницы Каталог
Модуль page_category.html содержит прототипы веб-страниц Категория 1
Модуль page_contacts.html содержит прототипы веб-страниц Контакты
Модуль page_main.html содержит прототипы веб-страниц Главная
Модуль app.py содержит код веб-приложений, который будет на любом GET-запросе возвращать страницу «Контакты»
Лицензия:
Данный проект не обладает лицензией

# Проект "Домашнее задание по Основам верстки"

## Описание:
Данный проект является образцом для создания HTML-документов со структурой страниц и подключенными 
к ним Bootstrap-стилями. 

## Установка:
### 1. Клонируйте репозиторий: 

        https://github.com/basinanatali-star/Django.git
        
### 2. Установите зависимости:

        pip install -r requirements.txt

## Использование:
Это учебный проект, поэтому можно использовать его как образец

### Модули проекта:
* Модуль page_catalog.html содержит прототип веб-страницы Каталог
* Модуль page_category.html содержит прототип веб-страницы Категория 1
* Модуль page_contacts.html содержит прототип веб-страницы Контакты
* Модуль page_main.html содержит прототип веб-страницы Главная
* Модуль app.py содержит код веб-приложения, которое будет на любой GET-запрос возвращать страницу «Контакты»
